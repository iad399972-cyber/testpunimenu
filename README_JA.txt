# PuniMenu Android ソース（ARM64向け）

## このZIPについて
- 黒×紫のフローティングメニューUI
- 画面上の丸いボタン、ドラッグ移動、設定パネル
- ON/OFF設定とスライダー値を端末内に保存
- APKのビルドをGitHub Actionsで実行できるワークフロー付き
- ABIは `arm64-v8a` を指定

**重要:** このプロジェクトはメニューUIのサンプルです。表示される「ワンパン」「無敵」などは設定UIの項目名にすぎず、ゲームのメモリを書き換えたり、パッチ値を適用したりしません。ゲームのバージョンに依存するオフセットを適用する機能は含めていません。

## iPhone/iPadではなくAndroid向け
このAPKはAndroid端末向けです。iOSではインストールできません。

## APKを作る手順（Android端末だけで進める場合）
1. GitHubにサインインし、新しい空のリポジトリを作ります（例: `PuniMenu`）。
2. このZIPを展開し、中のファイルとフォルダをリポジトリのルートにアップロードします。`app` と `.github` フォルダも必要です。
3. GitHubのリポジトリで **Actions** タブを開きます。
4. `Build PuniMenu APK` を選び、**Run workflow** を押します。初回はActionsの利用を有効にする必要がある場合があります。
5. 実行が成功したら、ワークフロー実行ページ下部の **Artifacts** から `PuniMenu-debug-APK` をダウンロードします。
6. ZIPを展開して `app-debug.apk` をAndroid端末へ保存し、端末の設定で許可したうえでインストールします。

## 初回起動
1. PuniMenuを開きます。
2. 「オーバーレイ権限を設定」を押します。
3. Android設定画面で「他のアプリの上に重ねて表示」を許可します。
4. アプリに戻り「メニューを起動」を押します。
5. 紫の「P」ボタンを押すとメニューが開きます。ボタンはドラッグで移動できます。

## 注意点
- Androidの機種・OSバージョンによって、オーバーレイや通知の許可画面の表記が異なります。
- GitHub Actionsのビルドは、GitHub側でAndroid SDKを取得して行います。ここでAPKそのものをビルド済みと保証するものではありません。
- Google Playのゲームアプリに対する改変や不正なメモリ変更、オンライン対戦の公平性を損なう用途には対応していません。
